네트워크 접근제어(NAC)

기기가 사내망에 붙는 순간 · 본문 5장

이 장비가 답하는 질문이 기기를 회사 네트워크에 붙여도 되는가

  1. 직원 노트북 · 프린터
  2. NAC (스위치 포트 · 무선)
  3. 사내 업무망
  4. 방화벽
  5. 인터넷

어디에 서 있나

NAC는 기기가 회사 네트워크에 붙는 자리마다 섭니다. 사무실 벽의 랜 포트에 노트북을 꽂거나 사내 와이파이에 붙는 순간, 스위치와 무선 공유기(AP)가 NAC에 「이 기기를 붙여도 되느냐」고 묻습니다. 방화벽이 회사 입구에서 통신을 거른다면, NAC는 회사 안쪽의 수백 개 포트마다 누가 꽂혔는지를 확인합니다.

무엇을 보고 판단하나

세 역할: 기기, 스위치, 인증 서버

표준 방식인 IEEE 802.1X에서는 세 역할이 등장합니다. 접속하려는 기기, 기기가 꽂힌 스위치, 판단을 내리는 인증 서버입니다. 인증을 통과하기 전까지 스위치 포트는 인증용 통신만 통과시킵니다. 기기가 아이디·비밀번호나 기기 인증서를 내밀면 스위치가 이를 인증 서버에 RADIUS로 전달하고, 인증 서버가 허용하면 그제야 포트가 열립니다. 앞 장의 VPN이 바깥에서 들어오는 사람을 RADIUS로 확인했다면, NAC는 안에서 꽂히는 기기를 같은 RADIUS로 확인합니다.

802.1X를 못 하는 기기

프린터, 출입 통제기, CCTV처럼 인증 프로그램을 넣을 수 없는 기기도 많습니다. 이런 기기는 미리 등록해 둔 MAC 주소(네트워크 카드마다 붙은 고유 번호)로 확인합니다. MAC 주소는 바꿔 쓸 수 있기 때문에, 이 방식은 802.1X보다 약합니다. 프린터의 MAC 주소를 흉내 낸 노트북이 프린터 자리에 꽂히면 통과할 수 있습니다.

들여보낼 자리를 정한다

NAC는 붙일지 말지만 정하지 않고, 어느 구역에 붙일지도 정합니다. 인증 서버가 허용하면서 「이 기기는 직원 구역 VLAN 20으로」라고 알려 주면 스위치가 그 포트를 해당 구역에 넣습니다. VLAN은 스위치 안에서 나눈 가상의 구역입니다. 백신이 꺼져 있거나 보안 패치가 빠진 기기는 치료용 서버에만 닿는 격리 구역으로 보내고, 조치가 끝나면 다시 검사해 직원 구역으로 옮깁니다.

전체 그림에서의 뜻

본문 5장의 2011년 농협 전산망 마비 사건에서 검찰이 지목한 출발점은 유지보수 업체 직원의 노트북이었습니다. 공격자가 반드시 바깥 인터넷에서 오지는 않는다는 것, 회사 안에 꽂히는 기기 하나하나가 입구가 될 수 있다는 것을 보여 준 사례입니다. NAC는 회사 안쪽에도 문을 두자는 생각에서 나온 장비이고, 그 생각은 본문 6장의 제로트러스트(위치만으로 믿지 않는다)로 이어집니다.

로그로 읽기

NAC 로그의 재료는 스위치와 인증 서버가 주고받은 RADIUS 메시지입니다. 802.1X에서 RADIUS를 어떻게 쓰는지는 RFC 3580이 정했습니다. 아래는 그 규칙에 맞춘 설명용 예시입니다. 계정, 주소, 포트 번호는 꾸민 값입니다. MAC 주소는 RFC 3580에 실린 예시 값을 그대로 썼습니다.

# 스위치 → 인증 서버 : Access-Request (붙여도 되나)
User-Name = "lee.sy"
NAS-IP-Address = 10.0.0.21
NAS-Port = 12
NAS-Port-Type = Ethernet
Calling-Station-Id = "00-10-A4-23-19-C0"

# 인증 서버 → 스위치 : Access-Accept (붙여라, 이 구역으로)
Tunnel-Type = VLAN
Tunnel-Medium-Type = 802
Tunnel-Private-Group-ID = "20"

속성 뜻: RFC 3580, IEEE 802.1X RADIUS Usage Guidelines(2003년 9월). User-Name, NAS-IP-Address, NAS-Port는 RFC 2865.

속성예시 값읽는 법
User-Namelee.sy누가 인증했나.
Calling-Station-Id00-10-A4-23-19-C0어느 기기인가. RFC 3580은 이 칸에 접속 기기의 MAC 주소를 대문자와 「-」로 적게 했습니다.
NAS-IP-Address · NAS-Port10.0.0.21 · 12어느 스위치의 몇 번 포트인가. 스위치 위치표가 있으면 「본관 7층 동쪽 12번 자리」처럼 실제 자리로 바뀝니다.
NAS-Port-TypeEthernet유선 포트로 붙었습니다.
Tunnel-Private-Group-ID"20"어느 구역(VLAN)으로 보냈나. 격리 구역 번호가 찍혔다면 점검에서 떨어진 기기입니다.

NAC 제품은 여기에 그 기기가 받은 IP 주소, 운영체제, 백신·패치 점검 결과를 붙여 기록합니다. 그래서 NAC 로그는 「MAC 주소 · IP 주소 · 사용자 · 스위치 포트」를 잇는 대응표가 됩니다.

이 로그로 답할 수 있는 질문

  • IP 주소 10.0.20.31은 어제 오후 3시에 누구의 어느 기기였나. 사내 PC는 주소를 그때그때 받아 쓰므로, 시각과 함께 NAC 기록을 봐야 정확합니다. 방화벽 로그의 내부 출발지를 사람과 자리로 바꿀 때 이 기록을 씁니다.
  • 등록되지 않은 기기가 어디에 꽂혔나. 거절 기록의 스위치와 포트 번호로 자리를 찾아갑니다.
  • 같은 MAC 주소가 같은 시각에 두 포트에서 보였나. 한 기기가 동시에 두 자리에 있을 수 없으므로 MAC 위조를 의심합니다.
  • 격리 구역으로 보낸 기기는 몇 대이고, 얼마 만에 조치됐나.

이 로그만으로는 모르는 것

NAC는 붙이는 순간을 판단하고 기록합니다. 붙은 뒤 그 기기 안에서 어떤 프로그램이 돌았는지는 EDR이, 그 기기가 어디와 통신했는지는 방화벽이 압니다.
